# Dataset

The notebooks expect the following local files:

- `earthquake_data.csv` — original dataset
- `preprocessedEarthquake.csv` — preprocessed dataset generated during the project

The original dataset was obtained from Kaggle:
https://www.kaggle.com/datasets/warcoder/earthquake-dataset

Place the CSV files in this `data/` folder before running the notebooks.

The notebooks were originally developed with the CSV files available in the working directory. If running them from this repository, update the CSV paths in the notebooks to `../data/<filename>.csv` as needed.
